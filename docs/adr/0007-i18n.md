# 0007 — i18n-Laufzeit: Proxy `t`, Deutsch im Start-Chunk

**Kontext.** Das Referenz-Spiel hat eine bewährte Lösung: `t` ist ein Proxy auf die aktive Sprache. Deutsch liegt im Start-Chunk, Englisch wird nachgeladen, und Wächter verhindern Texte, die beim Import kopiert werden.

**Entscheidung.**

- **Laufzeit:** `createI18n<Strings>({ de, load: { en: () => import(…) } })` in `@engine/react` liefert `t`, `setLocale`, `useLocale` und `initLocale`.
- **Texte:** `Strings = EngineStrings & GameStrings`. Die Engine-UI-Texte liegen in `@engine/ui` (`i18n/de.ts`, `i18n/en.ts`), die Spieltexte im Spiel. Die englische Datei hat denselben Typ. Fehlt ein Schlüssel, bricht `tsc`.
- **Spracherkennung:** `?lang=` → Gerätewahl (Prefs, nicht im Spielstand) → Browser (`de*` → Deutsch, sonst Englisch).
- **Wächter** in `@engine/testing`, für jedes Spiel:
  - kein Zugriff auf `t.` im Modul-Gültigkeitsbereich (AST);
  - keine beim Import kopierten Texte (Pseudo-Sprache);
  - vollständige Schlüssel, keine leeren Texte;
  - gleiche Platzhalter in beiden Sprachen.
- **Zahlen:** immer über `formatNumber(n, NUMBER_LOCALES[locale])`.

**Folgen.**
- Die Engine bleibt textfrei. Sie liefert `labelKey`s und Codes, die UI übersetzt.
