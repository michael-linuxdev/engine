## Icons und Store-Bilder

App-Icons und Store-Screenshots sind eigene Arbeit. Die Icons entstehen aus `games/<spiel>/public/icon-square.svg` (`npm run store:icons`), die Screenshots aus dem Spiel selbst (`npm run store:shots`). Es gibt keine Fremd-Assets.
